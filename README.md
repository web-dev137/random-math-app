# random-math-app
This app for demo work of Linear Algebra library
## Dependencies

This project requires:
- Linear Algebra library(https://github.com/web-dev137/linear-library)

## Installation

Install dependencies before building the project.
cmake -B build  -S .  -G "MinGW Makefiles" 
cmake --build build --target all 

## Run
cd buld
./random_math_app.exe
